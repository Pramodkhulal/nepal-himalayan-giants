# Above 8,000m: Nepal's Himalayan Giants

A responsive website showcasing Nepal's majestic mountains that rise above 8,000 meters. The project provides information about the world's highest Himalayan peaks, their geography, history, culture, and climbing significance.

## Features

- Responsive design for desktop and mobile devices
- Interactive navigation menu
- Detailed mountain information
- Image gallery
- Contact section
- Clean and modern user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
